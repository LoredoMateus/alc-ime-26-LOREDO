# Computational Linear Algebra - IME

This repository contains academic assignments, theoretical exercise lists, and Python implementations for the Álgebra Linear Computacional (ALC) course at Instituto Militar de Engenharia (IME).

**Author:** Mateus Barros Lorêdo

**Contents**
* **Exercise Lists:** Step-by-step PDF solutions for theoretical problems (matrix inversion, Laplace expansion, symmetric and orthogonal matrices, matrix norms).
* **Python Algorithms:** 
  * Back substitution algorithm for solving upper triangular systems with null-element validation.
  * Planar robot kinematics using 3x3 Homogeneous Transformation Matrices.

**Technologies Used**
* Python 3
* NumPy

**How to Use**
The PDF files contain the theoretical mathematical proofs. The `.py` scripts can be executed in any standard Python environment or terminal to validate the computational linear algebra concepts.
